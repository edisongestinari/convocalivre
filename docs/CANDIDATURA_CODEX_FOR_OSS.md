## 1. Por que este repositório é elegível? (até 500 caracteres)

O ConvocaLivre é um projeto open source MIT que ajuda candidatos de concursos públicos no Brasil a localizar menções em diários oficiais e distinguir menções de possíveis atos administrativos. Já possui interface Windows testada, CLI, testes em CI e correções documentadas com PDFs reais. É um projeto recente, ainda sem adoção ampla; sua importância potencial está em transparência cívica, rastreabilidade, proteção de dados e revisão humana.

**Contagem:** 443 caracteres.

## 2. Como você vai usar créditos de API no projeto? (até 500 caracteres)

Usarei os créditos para manutenção open source: revisão de pull requests, triagem de issues, geração de testes com editais fictícios, regressões e análise de segurança do parser de PDFs. Não enviarei nomes, CPFs ou PDFs contendo dados pessoais à API sem base legal e controles apropriados. As sugestões do modelo serão verificadas por testes e revisão humana antes de entrar no código.

**Contagem:** 385 caracteres.

## 3. Algo mais que devemos saber? (até 500 caracteres, opcional)

Projeto iniciado em 16/11/2026, ainda em pré-alfa. O repositório tem licença MIT, guia para colaboradores, CI e uma demonstração local validada no Windows. O benchmark externo é exploratório e foi usado para desenvolver correções; não alegamos precisão geral. Busca em API externa permanece beta por indisponibilidade do serviço. Quero ampliar testes independentes e manutenção aberta, sem apresentar o produto como sistema oficial de convocações.

**Contagem:** 447 caracteres.
