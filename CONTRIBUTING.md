# Como contribuir

Obrigado pelo interesse. Antes de abrir PR, abra uma issue descrevendo o problema e, se possível, um exemplo totalmente fictício que o reproduza.

1. Trabalhe em uma branch curta.
2. Inclua teste para bugs ou alterações no motor de análise.
3. Rode `python -m unittest discover -s tests -v`.
4. Evite publicar diários com dados pessoais sem fundamento legal; prefira exemplos sintéticos.
5. Não altere a saída para afirmar automaticamente nomeação, convocação ou autenticidade.
6. Documente limites e versões, e mantenha transparência sobre qualquer IA usada.

Revisões e merges serão feitos por mantenedor autorizado; o projeto não possui vínculo com órgãos públicos.
